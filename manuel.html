VAREC — Manuel utilisateur

Documentation officielle de VAREC 1.4.35, le field recorder multipiste professionnel pour macOS. Ce manuel couvre chaque fonction de l'application — de l'installation aux outils d'analyse avancés, en passant par la configuration timecode et la génération des sound reports.

1. Présentation

VAREC est un enregistreur audio multipiste destiné aux professionnels du son sur le terrain : cinéma, documentaire, reportage, captation live et post-production. L'application est native macOS, exploite l'interface audio CoreAudio de votre Mac et tire parti des architectures Apple Silicon comme Intel x86_64.

L'interface a été pensée pour rester minimaliste et lisible en tournage, tout en exposant les fonctions professionnelles indispensables : timecode externe, paires stéréo, métadonnées BWF, sound report exportable, upload cloud et fichiers projet réutilisables.

Fonctionnalités principales

  • Capture multipiste jusqu'à 512 canaux simultanés (selon l'interface CoreAudio)
  • Formats WAV 16 / 24 bits PCM, WAV 32 bits float et RF64 (fichiers > 4 Go sans split)
  • Sample rates de 44,1 kHz à 192 kHz
  • Sources timecode : LTC, MIDI MTC, Tentacle Sync E (Bluetooth BLE), Time of Day
  • Multi-disque simultané (vraie redondance temps réel, pas une copie post-enregistrement)
  • Métadonnées BWF / iXML complètes (scène, prise, notes, ingénieur, track list)
  • Sound Report exportable en PDF / CSV / HTML
  • Upload automatique vers Smash, Dropbox ou Cloudflare R2
  • VU mètres Instant Peak / RMS+PPM / True Peak avec peak hold configurable
  • Mapping MIDI du transport et des faders
  • Crash Recovery : headers WAV écrits en continu, aucun fichier corrompu en cas de coupure

2. Installation

Configuration requise

  • macOS 12 Monterey ou supérieur
  • Apple Silicon (M1, M2, M3, M4) ou Intel x86_64
  • Interface audio compatible CoreAudio (intégrée ou externe)
  • 4 Go de RAM minimum (8 Go recommandés au-delà de 64 canaux)
  • Espace disque libre suffisant — un disque rapide (SSD interne ou SSD externe USB 3 / Thunderbolt) est fortement recommandé

Installation

  1. Téléchargez le fichier VAREC-1.4.35-arm64.dmg (Apple Silicon) ou VAREC-1.4.35.dmg (Intel) depuis la page Télécharger ou directement sur varec.bernik.io.
  2. Double-cliquez le DMG puis glissez l'application VAREC.app dans le dossier Applications.
  3. Au premier lancement, macOS demande l'autorisation d'accès au microphone et au système de fichiers. Acceptez les deux.
  4. Ouvrez l'onglet PATCH et sélectionnez votre interface audio en entrée puis en sortie.
Permissions micro. Sur macOS, l'accès au microphone doit être autorisé dans Réglages Système → Confidentialité et sécurité → Microphone. Sans cette autorisation, VAREC ne verra aucun canal d'entrée — la liste sera vide dans l'onglet PATCH.
Astuce. Pour les sessions avec un grand nombre de canaux, branchez votre interface audio avant de lancer VAREC afin que CoreAudio l'expose dès le démarrage. Si l'interface est branchée après, utilisez le bouton 🔍 Scan dans l'onglet PATCH pour relancer la détection.

3. Démarrage rapide

Un premier enregistrement en six étapes :

  1. Lancez VAREC.
  2. Onglet PATCH : sélectionnez votre interface audio en entrée et en sortie. Laissez le sample rate sur AUTO pour utiliser le taux natif.
  3. Onglet REC : ajoutez les canaux nécessaires avec la touche T, ou utilisez ⌘+T pour la création en lot (Batch Inputs).
  4. Choisissez la profondeur de bits et le format (recommandé : 48 kHz / 32-bit Float WAV poly).
  5. Choisissez un ou plusieurs disques de destination dans le panneau Disques.
  6. Pressez Espace ou cliquez sur REC. Arrêtez avec un second Espace (split) ou le bouton STOP. Le fichier WAV est immédiatement disponible.
Auto-sauvegarde. Le projet est sauvegardé toutes les 5 secondes en tâche de fond. Vous pouvez fermer l'application sans craindre de perdre des prises ou des métadonnées.

4. Vue d'ensemble de l'interface

La fenêtre principale est organisée en trois zones et trois onglets.

Zones

  • Barre de transport (en haut) : bouton REC/STOP, false take, panic, minuterie (TC, TOD ou ELA), sélecteurs scène & take, sample rate, source audio.
  • Zone canaux (au centre) : un strip par canal — numéro, nom, contrôles ARM / MUTE / SOLO / LIEN, gain, VU mètre, indicateur peak.
  • Pied de page : statut disque(s) avec espace libre temps réel, statut cloud, indicateurs de licence et de version.

Onglets REC / PATCH / METADATA

OngletRaccourciRôle
REC⌘+1Vue d'enregistrement : strips canaux, VU mètres, transport.
PATCH⌘+2Sélection des interfaces d'entrée/sortie et assignation des canaux.
METADATA⌘+3Métadonnées projet, scène, prise, template de nommage.

Modes d'affichage

  • Standard — strips horizontaux, vue par défaut.
  • Fader — strips verticaux avec faders virtuels par canal et par groupe.
  • Compact — vue dense pour les sessions à très haut nombre de canaux.

Bascule entre orientation Horizontale et Verticale avec Tab. La touche Z active le zoom adaptatif (tous les canaux à la taille maximale possible).

Thèmes & polices

Le menu Vue → Thème propose quatre apparences :

  • Foncé — par défaut, optimisé pour le tournage de nuit et la lecture prolongée.
  • Clair — adapté à l'usage en intérieur diurne.
  • Fun — palette colorée pour l'ergonomie créative.
  • Minimal — niveaux de gris uniquement.

Quatre familles de polices sont disponibles via Vue → Police : Système, Monospace, Arrondie, Serif.

5. Interfaces audio (PATCH)

L'onglet PATCH centralise la sélection des interfaces audio. VAREC s'appuie sur CoreAudio : toute interface compatible Mac est utilisable, y compris Dante Virtual Soundcard, RME MADI, Focusrite Red, etc.

Détection

Au lancement, VAREC scanne automatiquement les interfaces disponibles. Le bouton 🔍 Scan relance la détection à chaud, par exemple après avoir branché une interface USB ou activé une Dante VSC.

Sélection

  • Interface d'entrée — celle dont vous allez enregistrer les canaux.
  • Interface de sortie — destination du monitoring casque / régie.
  • Sample rate — AUTO pour utiliser le taux natif, ou forcez 44 100 / 48 000 / 88 200 / 96 000 / 192 000 Hz.
  • Buffer — 512 / 1024 / 2048 / 4096 / 8192 frames. Augmentez si vous constatez des xrun (dropouts).
Changement à chaud. Modifier l'interface ou le sample rate pendant un enregistrement n'est pas possible. Arrêtez la prise au préalable. VAREC affichera un message d'erreur si vous tentez de changer en cours de prise.

6. Enregistrement multipiste

Armer les canaux

Cliquez sur le bouton R du strip (ou touche A sur le canal sélectionné) pour armer un canal. Seuls les canaux armés produisent un fichier audio. Maintenez ⌥ en cliquant pour armer tout / rien.

Démarrer une prise

Pressez Espace ou cliquez sur le bouton REC rouge. Le compteur démarre, les fichiers WAV sont ouverts pour chaque canal armé et écrits en continu sur tous les disques actifs.

Split & False Take

  • Split — un second Espace pendant l'enregistrement ferme proprement les fichiers en cours et en ouvre de nouveaux. Le numéro de prise s'incrémente automatiquement.
  • Arrêt — bouton carré ou menu Enregistrement → Arrêter. Les headers WAV sont finalisés avec la taille réelle.
  • False Take (✕ orange) — marque la prise courante comme à exclure du sound report. Utile en cas de fausse manip ou de prise gâchée.
  • Panic (⌥+P) — ferme et finalise tous les fichiers en cas de problème critique. À utiliser en dernier recours.
  • Reset Peaks (⌥+R) — remet à zéro les valeurs de hold des VU mètres.

Pré-roll

Un pré-roll de 0, 2, 5 ou 10 secondes peut être activé dans les préférences. Lorsque vous démarrez une prise, VAREC inclut les secondes précédant le déclenchement (capturées dans un buffer circulaire en permanence).

Auto Peak Marker

Lorsque l'option est cochée dans le menu Enregistrement, VAREC pose automatiquement un marqueur dans le header BWF chaque fois qu'un pic dépasse 0 dBFS. Ces marqueurs apparaissent ensuite dans le Sound Report.

Formats audio

Mode fichier

  • MONO — un fichier WAV par canal armé (une paire stéréo = un fichier stéréo).
  • POLY — un seul fichier multicanal regroupant tous les canaux armés. C'est le mode recommandé pour le cinéma et la post.

Nommage des fichiers

Dans l'onglet METADATA, vous définissez un template de nommage à l'aide de tokens :

Métadonnées BWF / iXML

Chaque fichier inclut automatiquement :

  • Timestamp BWF (OriginationTime, OriginationDate)
  • Timecode de départ et frame rate (TimeReference)
  • Scène, take, notes
  • Nom de chaque piste dans iXML/TRACK_LIST
  • Marqueurs horodatés TC

Split automatique

Pour éviter les fichiers trop volumineux, VAREC peut splitter automatiquement chaque prise selon des seuils par format :

FormatDurée max par défautPlafond

WAV 32F1 h 305 400 s
RF6424 h86 400 s

Les seuils se configurent dans Préférences → Record → Split automatique.

7. Liens stéréo & groupes

Liens stéréo

Deux canaux consécutifs peuvent être liés en paire stéréo. VAREC propose même une détection automatique de paires stéréo par analyse de la corrélation entre canaux adjacents.

  1. Cliquez sur l'icône chaîne du canal de gauche.
  2. Le canal suivant devient automatiquement le côté droit.
  3. Les VU mètres affichent désormais L (vert) et R (cyan) côte à côte.
  4. Le fichier WAV produit est un stéréo interleaved L[0], R[0], L[1], R[1]… avec le suffixe _STEREO.
Affichage fusionné. Activez Vue → Afficher entrée sous le nom pour fusionner visuellement les deux strips d'une paire stéréo dans une seule colonne, en gagnant en densité d'affichage.

Groupes

Pour regrouper plusieurs canaux (par exemple toutes les pistes d'un kit batterie ou toutes les pistes d'un comédien) :

  1. Sélectionnez plusieurs canaux (clic + ⇧).
  2. Pressez ⌘+G.
  3. Donnez un nom au groupe.

En mode Fader, chaque groupe expose un fader global et des boutons MUTE / SOLO appliqués à tous ses canaux. Les groupes apparaissent également dans le Sound Report.

Contrôles par canal

ContrôleEffet
ARM (A)Active le canal pour l'enregistrement.
MUTE (M)Coupe le canal du monitoring (l'enregistrement reste actif si armé).
SOLO (S)Isole le canal en écoute. Plusieurs solos sont cumulatifs.
LIEN (chaîne)Crée une paire stéréo avec le canal suivant.
NomDouble-clic pour renommer (apparaîtra dans le nom de fichier et dans iXML).

✕ MUTE et ✕ SOLO (en haut de la zone canaux) désactivent tous les mutes ou tous les solos en un clic.

8. Notes de prise

Pendant l'enregistrement, pressez N ou cliquez sur l'icône 📝 dans la barre de transport pour ouvrir le panneau NOTES — TAKE EN COURS.

  • ↵ Entrée — sauvegarde la note et ferme le panneau.
  • ⇧+↵ Entrée — passage à la ligne sans fermer.
  • L'historique des notes de la prise courante est listé au-dessus du champ de saisie, avec horodatage TC.

Les notes sont attachées à la prise dans le fichier projet et apparaissent dans le Sound Report. Un marqueur horodaté TC est également écrit dans le header BWF de chaque fichier concerné.

En plus des notes texte, vous pouvez poser des marqueurs rapides à tout moment d'une simple touche, sans ouvrir de panneau. Les marqueurs de peak (lorsque l'option Auto Peak Marker est active) s'ajoutent automatiquement à cette liste.

9. Multi-disque simultané

VAREC peut écrire le même fichier WAV sur plusieurs disques simultanément. C'est une vraie redondance temps réel — pas une copie effectuée après coup.

  • Chaque disque actif reçoit son propre flux d'écriture indépendant.
  • Si un disque se déconnecte ou tombe en panne pendant l'enregistrement, les autres continuent sans interruption.
  • Le débit d'écriture est affiché par disque en temps réel.
  • Menu contextuel sur chaque disque : ouvrir dans le Finder, démonter, exclure du prochain enregistrement.

Sélection des disques

Dans le panneau Disques (à gauche de la zone canaux), cochez chaque disque cible. L'espace libre est affiché et mis à jour pendant l'enregistrement. Une alerte apparaît dès qu'un disque passe sous le seuil de sécurité (configurable dans les préférences).

Astuce. Pour un projet critique, branchez un SSD Thunderbolt en plus du SSD interne. La perte d'un disque ne compromet pas la prise. Le Sound Report indique sur quel(s) disque(s) chaque fichier a été écrit.

Organisation sur disque

Chaque session crée un dossier VAREC/{projet}/{scene}/ sur chaque disque actif, contenant les fichiers WAV et un fichier projet .varec.json. La structure est identique sur tous les disques redondants.

10. Timecode

Cliquez sur la minuterie en haut de fenêtre pour choisir la source de timecode parmi quatre modes :

  • TC — timecode externe (LTC analogique, MIDI MTC ou Tentacle Sync E en Bluetooth).
  • TOD — Time Of Day, horloge système.
  • ELA — Elapsed Time, compteur relatif au début de la prise.

LTC (Linear Timecode)

Reçoit le LTC sur un canal d'entrée audio dédié. VAREC utilise une hystérésis zero-crossing avec PLL pour une lecture stable même en présence de bruit ou de hum. Jam sync automatique sur perte de signal puis reprise.

Assignez l'entrée timecode dans Préférences → Timecode → Entrée LTC en sélectionnant le canal audio source.

Tentacle Sync E (Bluetooth)

Appairez le module Tentacle Sync E avec votre Mac via Bluetooth. VAREC le détecte automatiquement et lit le TC sans câble. La latence est compensée. C'est la solution la plus pratique en tournage léger.

Time of Day (TOD)

Utilise l'horloge système comme source TC. Idéal pour le documentaire et le reportage où la synchronisation à l'heure réelle simplifie la post-production.

Statut TC

Une LED à côté de la minuterie indique l'état :

  • Vert — TC reçu et verrouillé.
  • Orange — découverte ou jam sync en cours.
  • Rouge — perte de signal.

Frame rate

Le frame rate (23,976 / 24 / 25 / 29,97 / 30 fps, drop-frame ou non-drop) se règle dans Préférences → Timecode. Le frame rate sélectionné est inscrit dans le header BWF (TimeReference) et dans le bloc iXML, garantissant la compatibilité avec tous les NLE professionnels (Pro Tools, Avid, DaVinci Resolve, Reaper).

11. Sound Report PDF

Le Sound Report est généré à la demande depuis les métadonnées de session. Il rassemble toutes les informations utiles pour la post-production.

Contenu

  • En-tête de production — titre, réalisateur, ingénieur son, lieu, date, contact.
  • Tableau des prises — scène, take, TC IN, TC OUT, durée, notes, ingénieur, false take éventuel.
  • Marqueurs de peak par prise (lorsque Auto Peak Marker est actif).
  • Statistiques de session — nombre de prises, durée totale, espace utilisé, disque(s) cible.
  • Lien cloud par prise (si l'upload est activé).

Exports disponibles

ExportUsage
PDFAperçu intégré + impression directe via Electron printToPDF. PDF vectoriel natif.
CSVCompatible Excel, Google Sheets, base de données. Idéal pour intégration dans un outil de production.

12. VU mètres & outils d'analyse

Modes de metering

  • Instant Peak — niveau échantillon par échantillon, idéal pour repérer le moindre transitoire.
  • RMS + PPM — barre RMS large + aiguille PPM fine superposée. Le mode classique broadcast.
  • True Peak — détection inter-sample peaks (4× oversampling). Indispensable pour le mastering broadcast aux normes EBU R128.

L'indicateur de clip rouge est latché dès 0 dBFS — la barre peak rouge reste persistante jusqu'au reset (clic sur le strip ou ⌥+R).

Réglages

ParamètrePlageEffet
Attaque1 – 50 msVitesse de montée de la barre.
Release50 – 3 000 msVitesse de descente.
MesuredBFS / dBuRéférence d'affichage.
Plage–24 à –90 dBÉtendue verticale de la barre.
Peak hold0,5 – 30 sDurée d'affichage du pic latché.

Tous ces réglages sont accessibles via Vue → VU Mètre… et peuvent être sauvegardés en presets utilisateur.

Analyseur de phase

L'outil Phase calcule le décalage GCC-PHAT entre deux canaux sur une fenêtre de 15 secondes. Il affiche le coefficient de corrélation et le délai estimé en millisecondes. Le délai peut être appliqué au monitoring (sans toucher au fichier enregistré) et est noté dans les métadonnées iXML.

Cas typique : aligner un micro-cravate et un micro perche pour éviter les annulations de phase.

Spectrogramme & histogramme

Clic droit sur un canal → Spectre ouvre un analyseur FFT temps réel avec spectrogramme défilant et histogramme de niveaux. Utile pour identifier rapidement un souffle, une fréquence parasite ou un déséquilibre tonal.

13. Partage cloud

VAREC peut uploader chaque prise automatiquement vers un service cloud dès la fin de l'enregistrement, sans quitter l'application.

Providers supportés

  • Smash — partage temporaire par lien direct, expiration configurable. Idéal pour transférer rapidement une prise à la post.
  • Dropbox — synchronisation vers un dossier choisi via OAuth.
  • Cloudflare R2 — stockage S3-compatible avec page HTML de partage, configuration par profil.

Configuration

  1. Ouvrez Préférences → Cloud.
  2. Sélectionnez le provider et authentifiez-vous (OAuth pour Dropbox, clé API pour R2, instant pour Smash).
  3. Cochez Upload automatique.

Statut

La carte cloud en bas de fenêtre affiche en permanence l'un des états suivants :

StatutSignification
unconfiguredAucun provider configuré.
readyConfiguré et prêt à uploader la prochaine prise.
uploadingUpload en cours, avec barre de progression.
doneUpload terminé. Cliquez pour copier le lien de partage.
errorErreur d'upload (clic pour détails). VAREC réessaye automatiquement à intervalles croissants.

14. Crash Recovery

VAREC est conçu pour qu'aucune coupure n'entraîne de perte de fichiers. Cette robustesse est rendue possible par plusieurs mécanismes complémentaires.

Mécanismes

  • Les headers WAV (taille des chunks data) sont mis à jour en continu pendant l'enregistrement — pas seulement à la fin.
  • Le fichier projet .varec.json est écrit de manière atomique (écriture dans un fichier temporaire puis renommage).
  • Un watchdog surveille la latence d'écriture par disque et alerte si un disque ralentit anormalement (signe d'un disque qui sature ou qui se déconnecte).
  • L'auto-sauvegarde du projet a lieu toutes les 5 secondes.

En cas de coupure

Coupure de courant, kernel panic, débranchement d'un disque : les fichiers WAV présents sur disque restent parfaitement lisibles jusqu'au dernier bloc écrit. Aucun outil de récupération n'est nécessaire.

Test de fiabilité. Les préférences (Record → Test de fiabilité) lancent une prise factice de 30 secondes puis vérifient l'intégrité des fichiers produits. Idéal pour valider un nouveau SSD avant un tournage critique.

15. Contrôle MIDI

VAREC accepte le pilotage du transport et des faders via MIDI. Idéal pour intégrer VAREC à une surface de contrôle, un footswitch ou un pédalier en régie.

Configuration

  1. Ouvrez Préférences → MIDI.
  2. Sélectionnez le port MIDI d'entrée (USB, Bluetooth ou virtuel).
  3. Pour chaque action (REC, STOP, PLAY, SPLIT, Marqueur, Take +1), cliquez sur Learn puis envoyez la Note ou le CC depuis votre contrôleur. L'assignation est mémorisée immédiatement.
  4. Pour les faders : choisissez le canal MIDI et le CC de base. Les canaux VAREC sont assignés en ordre croissant à partir de ce CC.
Astuce. Un footswitch MIDI assigné à REC/STOP libère les mains pendant l'enregistrement — utile pour la captation seul, sans assistant.

16. Fichiers projet (.varec)

Un fichier .varec contient toute la configuration d'un projet : il est portable, partageable et réutilisable.

Contenu

  • Liste des canaux, noms, paires stéréo, groupes
  • Mode fichier, format, sample rate, taille de buffer
  • Métadonnées projet (titre, ingénieur, lieu), template de nommage
  • Identifiants cloud (chiffrés localement)
  • Marqueurs et notes de prises horodatés TC

Opérations

Templates

Les templates sont stockés dans ~/Library/Application Support/VAREC/templates/ et réutilisables pour démarrer un nouveau projet pré-configuré (par exemple : « 8 micros HF + 1 perche + 1 ambiance », « 16 pistes batterie », etc.).

17. Préférences

Accessibles via ⌘+, ou le bouton ⚙ dans la barre de transport. Les préférences sont regroupées en six onglets.

Général

  • Mode Fader — faders virtuels par canal et par groupe.
  • Mode Compact — densité d'affichage maximale.
  • Mode Éco — réduit le CPU pour de très grands nombres de canaux (utile au-delà de 128 ch).
  • Pré-roll — 0 / 2 / 5 / 10 s.

Audio

  • Interfaces d'entrée et de sortie par défaut
  • Compensation de latence (Auto ou offset manuel en ms)
  • Politique de sample rate (AUTO ou forcé)

Record

  • Split automatique par format (voir §6)
  • Journalisation des xrun dans un fichier log
  • Test de fiabilité d'enregistrement
  • Auto Peak Marker (seuil dBFS configurable)

Timecode

  • Frame rate (23,976 → 30 fps, drop / non-drop)
  • Source TC (LTC / MIDI MTC / Tentacle BLE / TOD)
  • Scan et appairage Bluetooth Tentacle
  • Hystérésis zero-crossing LTC

Meters

  • Style VU (Instant Peak / RMS+PPM / True Peak)
  • Unités (dBFS ou dBu)
  • Constantes d'attaque et de release
  • Presets utilisateur

Cloud & MIDI

Voir §13 Partage cloud et §15 Contrôle MIDI.

19. FAQ & Dépannage

Aucun canal d'entrée détecté

  • Vérifiez l'autorisation micro dans Réglages Système → Confidentialité & sécurité → Microphone.
  • Cliquez sur 🔍 Scan dans l'onglet PATCH après avoir branché l'interface.
  • Pour les interfaces Dante VSC / SoundGrid : assurez-vous que le service hôte est lancé avant VAREC.

Dropouts ou xrun pendant l'enregistrement

  • Augmentez la taille du buffer (1024 → 2048 → 4096 frames).
  • Utilisez un disque rapide : SSD interne, SSD externe USB 3 ou Thunderbolt. Évitez les disques mécaniques au-delà de 16 canaux.
  • Désactivez les antivirus en temps réel sur le dossier de capture.
  • Activez le Mode Éco si vous enregistrez beaucoup de canaux (> 128).
  • Fermez les applications gourmandes en arrière-plan (Slack, Chrome, etc.).

Timecode non reçu

  • Vérifiez que le frame rate côté caméra et côté VAREC sont identiques.
  • Pour Tentacle : assurez-vous que le Bluetooth Mac est actif et que le module est en mode BLE (pas BLE+audio).
  • Pour LTC : vérifiez le niveau du signal sur l'entrée audio assignée. Trop faible ou saturé empêche le décodage.
  • Une LED orange permanente indique un jam sync impossible : redémarrez la source TC.

Activation de licence refusée

  • Vérifiez le format de la clé : XXXX-XXXX-XXXX-XXXX.
  • Une clé bêta peut être expirée — contactez le support pour renouvellement.
  • Réessayez après suppression du fichier de licence stocké dans ~/Library/Application Support/VAREC/licence.json.

Comment activer ma licence ?

Ouvrez Licence → Activer une licence… et collez le numéro reçu par email au format XXXX-XXXX-XXXX-XXXX. La licence est perpétuelle, liée à votre adresse email. Le menu Licence affiche en permanence le mode courant (Gratuit / Essai N jours restants / Licence active).

Puis-je enregistrer plus de 64 canaux sans licence ?

Non, la version sans licence est limitée à 64 canaux. La licence Pro débloque jusqu'à 512 canaux et active toutes les fonctions avancées (Sound Report, Cloud, MIDI, etc.).

VAREC fonctionne-t-il avec Dante / AVB / MADI ?

Oui, tant que l'interface est exposée par CoreAudio. C'est le cas de Dante Virtual Soundcard, des cartes RME MADI, Focusrite Red, Universal Audio Apollo, etc.

Pourquoi le 32-bit Float ?

Le 32-bit Float offre une dynamique pratiquement illimitée (~1500 dB). Vous ne pouvez plus saturer numériquement : un transitoire à +20 dBFS reste parfaitement récupérable en post sans distorsion.

Que se passe-t-il si mon Mac tombe en panne ?

Les fichiers WAV sur disque restent lisibles jusqu'au dernier bloc écrit grâce à la mise à jour continue des headers. Voir §14 Crash Recovery.

Où sont stockées les sessions ?

Chaque session crée un dossier VAREC/{projet}/{scene}/ sur chaque disque actif, contenant les fichiers WAV et un fichier projet .varec.json.

Envoyer un rapport de crash

Menu Aide → Envoyer rapport de crash. Joignez la sortie de Aide → Afficher les logs pour un diagnostic plus rapide.
