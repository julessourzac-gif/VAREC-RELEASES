VAREC — Manuel utilisateur

Bienvenue dans la documentation officielle de VAREC, le field recorder multipiste professionnel pour macOS. Ce manuel couvre toutes les fonctionnalités de la version 1.4.35.

1. Présentation

VAREC est un enregistreur audio multipiste destiné aux professionnels du son sur le terrain (cinéma, documentaire, reportage, captation live). Il fonctionne nativement sur macOS (Apple Silicon et Intel) et exploite l'interface audio CoreAudio de votre Mac.

  • Jusqu'à 512 canaux simultanés
  • WAV 16, 24 et 32-bit Float
  • Fréquences d'échantillonnage jusqu'à 192 kHz
  • Timecode LTC, Tentacle BLE, Time of Day
  • Enregistrement multi-disque simultané (redondance)
  • Sound Report PDF intégré

2. Installation

Configuration requise

  • macOS 12 Monterey ou supérieur
  • Apple Silicon (M1, M2, M3, M4) ou Intel x86_64
  • Interface audio CoreAudio (intégrée ou externe)
  • 4 Go de RAM minimum (8 Go recommandés au-delà de 64 canaux)

Installation

  1. Téléchargez le fichier .dmg correspondant à votre Mac depuis la page Télécharger.
  2. Ouvrez le DMG puis glissez l'application VAREC.app dans le dossier Applications.
  3. Au premier lancement, autorisez l'accès au micro et au système de fichiers depuis les Réglages Système → Confidentialité et sécurité.
  4. Sélectionnez votre interface audio dans le sélecteur Source audio en haut à droite.
Astuce. Pour les sessions avec un grand nombre de canaux, branchez votre interface audio avant de lancer VAREC afin que CoreAudio l'expose dès le démarrage.

3. Démarrage rapide

  1. Lancez VAREC.
  2. Sélectionnez votre interface audio et le nombre de canaux dans la barre supérieure.
  3. Choisissez la fréquence et la profondeur de bits (recommandé : 48 kHz / 32-bit Float).
  4. Choisissez un ou plusieurs disques de destination dans le panneau Disques.
  5. Cliquez sur le bouton REC (ou pressez la barre d'espace).
  6. Arrêtez l'enregistrement avec STOP. Le fichier WAV poly est immédiatement disponible.

4. Interface

L'interface se compose de quatre zones principales :

  • Barre supérieure — REC/STOP, timer, timecode, source audio, fréquence/bits, sélecteur de scène & take.
  • Liste des canaux — Un strip par canal : numéro, nom (renommable), arming (R), solo/mute, gain, VU mètre, peak.
  • Panneau Disques — Affiche les disques actifs, l'espace libre, le débit d'écriture en temps réel. Clic droit pour ouvrir dans le Finder.
  • Panneau Métadonnées — Scène, take, notes, marqueurs.

Modes d'affichage

  • Standard — vue par défaut, strips horizontaux.
  • Fader — strips verticaux avec faders.
  • Compact — vue dense pour les sessions à très haut nombre de canaux.

5. Enregistrement multipiste

Armer les canaux

Cliquez sur le bouton R du strip pour armer un canal. Seuls les canaux armés sont enregistrés. Maintenez Alt en cliquant pour armer tout / rien.

Format de fichier

VAREC produit un fichier WAV polyphonique par session (BWF avec iXML embarqué). Les métadonnées suivantes sont incluses :

  • Timestamp BWF (OriginationTime, OriginationDate)
  • Timecode de départ et frame rate
  • Scène, take, notes
  • Nom de chaque piste (iXML/TRACK_LIST)
  • Marqueurs horodatés TC

Profondeur de bits

Le 32-bit Float est recommandé : aucune limite de headroom, aucune saturation numérique. Les fichiers sont compatibles Pro Tools, Reaper, Davinci Resolve, Avid Media Composer.

6. Timecode

VAREC supporte trois sources de timecode, sélectionnables au clic sur la zone TC de la barre supérieure :

LTC (Linear Timecode)

Reçoit le LTC sur un canal d'entrée audio dédié. Hystérésis zero-crossing avec PLL pour une lecture stable même en présence de bruit. Jam sync automatique sur perte de signal.

Tentacle BLE

Connexion Bluetooth Low Energy aux Tentacle Sync E. Lecture du TC sans câble. Latence compensée.

Time of Day (TOD)

Utilise l'horloge système comme source TC. Idéal pour le documentaire et le reportage où la synchronisation à l'heure réelle simplifie la post-production.

BWF/iXML. Le timecode de départ est inscrit dans le header BWF (TimeReference) et dans le bloc iXML, garantissant la compatibilité avec tous les NLE professionnels.

7. Multi-disque simultané

VAREC peut écrire le même fichier WAV sur plusieurs disques simultanément. C'est une vraie redondance temps réel, pas une copie post-enregistrement.

  • Chaque disque actif reçoit son propre flux d'écriture indépendant.
  • Si un disque se déconnecte ou tombe en panne pendant l'enregistrement, les autres continuent sans interruption.
  • Le débit d'écriture est affiché par disque en temps réel.
  • Menu contextuel sur chaque disque : ouvrir dans le Finder, démonter, exclure du prochain enregistrement.

8. VU mètres & outils d'analyse

Modes de metering

  • Instant Peak — niveau échantillon par échantillon.
  • RMS + PPM — RMS lissé avec aiguille PPM par-dessus.
  • True Peak — détection inter-sample peaks (4× oversampling).

Indicateur de clip rouge latché dès 0 dBFS. Barre peak rouge persistante jusqu'au reset (clic sur le strip).

Analyseur de phase

Analyse de phase à la demande sur 15 secondes pour deux canaux. Affiche le coefficient de corrélation et le délai estimé. Le délai peut être appliqué au monitoring (sans toucher au fichier enregistré) et est noté dans les métadonnées du fichier.

Spectrogramme & histogramme

Analyse spectrale FFT par canal. Histogramme de distribution des niveaux pour identifier rapidement les anomalies (souffle, saturation).

9. Sound Report PDF

Le Sound Report est généré automatiquement à partir des métadonnées de session. Exportez-le via Fichier → Exporter Sound Report PDF.

Contenu

  • En-tête de production (titre, réalisateur, ingénieur son, lieu, date)
  • Liste exhaustive des prises : scène, take, TC IN, TC OUT, durée
  • Notes et marqueurs de peak par prise
  • Statistiques de session (nb. de prises, durée totale, espace utilisé)

L'aperçu intégré permet de vérifier le rendu avant export. L'impression directe utilise printToPDF d'Electron pour un PDF natif vectoriel.

10. Partage cloud

VAREC intègre l'upload direct des prises vers :

  • Smash — partage par lien direct, expiration configurable.
  • Dropbox — upload OAuth dans un dossier dédié.
  • Cloudflare R2 — S3-compatible, configuration par profil.

Le lien de partage est copié dans le presse-papiers à la fin de l'upload. Tout se fait sans quitter VAREC.

11. Crash Recovery

VAREC est conçu pour qu'aucune coupure n'entraîne de perte de fichiers :

  • Les headers WAV (taille des chunks data) sont mis à jour en continu pendant l'enregistrement.
  • Le projet est écrit de manière atomique (écriture dans un fichier temporaire puis renommage).
  • Un watchdog surveille la latence d'écriture et alerte si un disque ralentit.
  • En cas de coupure de courant ou de crash, les fichiers WAV présents sur disque sont lisibles immédiatement, jusqu'au dernier bloc écrit.

12. Contrôle MIDI

VAREC peut être contrôlé par des messages MIDI (CC ou Notes) depuis une surface de contrôle ou une régie. Configuration dans Préférences → MIDI :

  • REC / STOP
  • Marqueur
  • Incrément Take
  • Sélection scène

Mode apprentissage : cliquez sur "Apprendre" puis envoyez le message MIDI à assigner.

14. FAQ

Comment activer ma licence ?

Ouvrez VAREC → À propos → Licence et collez le numéro reçu par email après votre achat. La licence est perpétuelle, liée à votre adresse email.

Puis-je enregistrer plus de 64 canaux sans licence ?

Non, la version sans licence est limitée à 64 canaux. La version complète débloque jusqu'à 512 canaux.

VAREC fonctionne-t-il avec Dante / AVB / MADI ?

Oui, tant que votre interface est exposée par CoreAudio. C'est le cas de Dante Virtual Soundcard, des cartes RME MADI, Focusrite Red, etc.

Pourquoi le 32-bit Float ?

Le 32-bit Float offre une dynamique pratiquement illimitée (~1500 dB). Vous ne pouvez plus saturer numériquement : un crête à +20 dBFS reste parfaitement récupérable en post.

Que se passe-t-il si mon Mac tombe en panne ?

Les fichiers WAV sur disque restent lisibles jusqu'au dernier bloc écrit grâce à la mise à jour continue des headers (voir Crash Recovery).

Où sont stockées les sessions ?

Chaque session crée un dossier VAREC/SCENE/ sur chaque disque actif, contenant les fichiers WAV et un fichier de projet .varec.json.

Comment contacter le support ?

Écrivez à contact@bernik.io. Joignez les logs (VAREC → Aide → Révéler les logs) si vous rapportez un bug.
